Path-Level Guardbanding / Over-constraining (RCV Paper Strategy):

    Use when: The design has barely met timing (WNS >= 0) or Vivado's router is being "lazy" and skipping optimizations.

    Concept: Force the router/placer to escape local optima by artificially tightening the timing requirement.

    Execution: Use run_tcl to apply set_clock_uncertainty -setup <value> [get_clocks <clock_name>] (e.g., add 0.050 to 0.250ns of uncertainty).

    Follow with phys_opt_design -directive Explore or route_design -directive Explore, then remove the uncertainty (set_clock_uncertainty -setup 0) and check the true WNS.

Blockage-Aware Anchoring & Sector Tolerance (AMF-Placer 2.0 Strategy):

    Use when: Critical paths repeatedly cross major architectural blockages (like PCIe hard blocks or IO columns).

    Execution: If standard Pblocks fail, generate highly targeted, tight Pblocks (anchors) exactly at the crossing boundaries using create_and_apply_pblock.

    Tolerance Rule: Accept a temporary degradation in WNS for one iteration if it significantly reduces routing congestion or breaks up a dense logic cluster, as the subsequent iteration will likely achieve a global optimum.

LUT Pin Rearrangement (OpenPARF Strategy):

    Use when: You need to shave off picoseconds from a stubborn critical path that is already optimally placed.

    Concept: Internal CLB routing delays vary by pin. Swapping logically equivalent pins utilizes faster multiplexer paths.

    Execution: Use Vivado Tcl phys_opt_design -directive AlternateFlowWithRetiming or Explore which aggressively enables pin-swapping, or map signals to faster input pins via RapidWright fine-grained routing modifications.

Physical Optimization (Post-place/route fine-tuning):
